# TruePas industry page images: Kimi prompts

42 images: 6 journey steps for each of the 7 industry pages (`/industries/<slug>`). The hero images stay as they are.

## How to use
1. Paste one prompt at a time into Kimi (image generation plugin). Each prompt is complete on its own, including the shared style.
2. Generate 2–4 variants and pick the one where hands, faces and on-screen text look right. If screen text comes out garbled, regenerate; the TruePas wordmark and the green tick matter most.
3. Save each pick as PNG or JPG with the exact file name shown (e.g. `airports-1-link-trip.png`) in the folder `5-Oct/Industries/`.
4. Tell Claude when they're in: they get optimised to WebP and placed on the right step.

Size: 5:4 landscape, at least 1600 × 1280 px. The website shows them at about 347 × 277 px (desktop), with a number badge in the top-left corner.
